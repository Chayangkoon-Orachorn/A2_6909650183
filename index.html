Client และ Server

เมื่อเปิดไฟล์ index.html จากเครื่องของตนเอง จะมี Client คือเว็บเบราว์เซอร์ เช่น Chrome หรือ Edge ทำหน้าที่อ่านและแสดงผล HTML และ CSS แต่ยังไม่มี Server เพราะเปิดไฟล์จากเครื่องโดยตรง (Local File) ไม่ได้มีเครื่องที่ให้บริการเว็บผ่านเครือข่าย

How I Built It

  1. วางโครงสร้างเว็บไซต์ด้วย HTML
  2. แบ่งเนื้อหาออกเป็นแต่ละ Section
  3. ตกแต่งด้วย CSS เช่น สี พื้นหลัง ฟอนต์ และการจัดวาง
  4. ทดสอบเปิดเว็บไซต์ในเว็บเบราว์เซอร์และปรับแก้รูปแบบ

Reflection

ปัญหาและความท้าทาย

ช่วงแรกยังไม่คุ้นเคยกับการจัดวางองค์ประกอบของ HTML และการตกแต่งด้วย CSS จึงทดลองปรับหลายครั้ง จนเข้าใจการใช้ margin, padding และการเลือกสีให้เหมาะสม

สิ่งที่เข้าใจมากขึ้น

เข้าใจการทำงานของ HTML และ CSS มากขึ้น เช่น การใช้แท็กต่าง ๆ การจัดวางเนื้อหา และการปรับแต่งสไตล์ ทำให้สามารถสร้างเว็บไซต์ที่ดูดีและใช้งานได้

สิ่งที่อยากพัฒนาต่อ

อยากเขียน css ให้ซับซ้อนขึ้นเช่นการตกแต่งหน้าเว็ปอย่างละเอียด
